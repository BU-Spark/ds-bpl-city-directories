# Boston City Directories

BU Spark! / CDS DS701 project with Boston Public Library and the Leventhal Map
& Education Center, working with the 1916 Boston Directory.

The active work is a portable **Python CLI + Tesseract** workflow for Vol. 1
(A–O). Start with [fa26/README.md](fa26/README.md) for setup, commands, scope and
current progress. OCR is followed by entry extraction and geocoding in later
stages; full-volume OCR is not yet complete.

- [fa26/](fa26/): active semester workflow, configuration and source manifests.
- [Model comparison evidence](fa26/archive/model_comparison/README.md): completed
  five-model experiment, original seven scans, outputs and selection rationale.
- [dataset-documentation/](dataset-documentation/): original dataset templates.

The old Colab workflow has been retired. Downloaded scans, weights, local
environments and production results are kept out of Git. The historical
comparison evidence remains versioned so the model-selection process is visible.

Project documents and client presentations are maintained in the parent workspace.
